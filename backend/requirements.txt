# --- Production WSGI server ---
# Flask-SocketIO needs a co-operative worker to serve WebSocket; gunicorn's sync
# and threaded workers can only do HTTP long-polling. gevent is the only such
# worker gunicorn still ships — 26.2.0 removed the eventlet worker entirely
# (verified: SUPPORTED_WORKERS has no eventlet entry), so eventlet is not an
# option regardless of the package being installable.
#
# gevent-websocket supplies the GeventWebSocketWorker that upgrades connections
# to WebSocket. It is unmaintained (0.10.1, 2017) but imports and runs fine on
# gevent 26.x. If it ever breaks, plain `-k gevent` still works and Socket.IO
# degrades to long-polling, which this app's low-frequency progress events can
# live with.
#
# Exactly one worker — progress events are addressed to an in-memory Socket.IO
# sid, so a second worker would silently drop the events belonging to the other.
gunicorn==26.2.0
gevent==26.8.0
gevent-websocket==0.10.1
