# Local development dependencies: production + the local ML stack.
#
#   pip install -r requirements-local.txt
#
# The CUDA build of torch is NOT installed by this file. Plain `pip install
# torch` silently gives you the CPU-only wheel, which makes local generation
# ~10-20x slower. On an NVIDIA machine install it explicitly first:
#
#   pip install torch==2.11.0+cu128 --index-url https://download.pytorch.org/whl/cu128
#   pip install -r requirements-local.txt
#
# On a machine with no NVIDIA GPU, plain `torch==2.11.0` is fine — llm.py finds
# no CUDA device and summarizer.py falls back to a lighter BART model.

-r requirements.txt
